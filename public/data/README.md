# NariAid Cycle Prediction Data

- `FedCycleData071012.csv`: reference cycle dataset used to derive baseline cycle length, ovulation, luteal phase, menses length, and fertile-window statistics.
- `example-woman-tracker-50-days.csv`: synthetic 50-day NariAid tracker example for local testing and demos.

The app prediction UI blends the reference dataset with NariAid tracker/profile data. The iOS companion uses the bundled example tracker until it is connected to the web backend.
